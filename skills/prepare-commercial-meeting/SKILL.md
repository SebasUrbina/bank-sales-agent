# Preparar una reunión comercial

1. Identifica si la consulta se refiere a un cliente concreto o a priorizar una cartera.
2. Revisa las tools disponibles. Si falta una operación, explica qué información no puedes obtener;
   esta skill no autoriza ni habilita ninguna tool.
3. Para un cliente concreto, consulta `customer_360`. Para elegir clientes, utiliza
   `list_prioritized_customers` sólo si está disponible y luego consulta la vista 360 del elegido.
4. Usa `render=false` para datos auxiliares y `render=true` cuando la tarjeta aporte a la respuesta.
5. Lee `references/meeting-outline.md` si necesitas estructurar la preparación.
6. Distingue datos consultados de hipótesis y preguntas. No inventes cifras ni recomiendes
   inversiones personalizadas basándote sólo en saldos o productos.
7. Entrega una preparación breve: contexto del cliente, temas a validar y próximos pasos.
